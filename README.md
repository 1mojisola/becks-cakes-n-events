# Becks Cakes N Events

Static responsive website. Replace gallery placeholders with Becks' 8 photos and 2 short videos when available. Add exact services/prices when provided.

## Deploy on Vercel
1. Create a GitHub repository named `becks-cakes-n-events`.
2. Upload `index.html` and `README.md`.
3. In Vercel, choose Add New -> Project -> Import the GitHub repository.
4. Framework Preset: Other (or leave detected/default for static site).
5. Build Command: leave empty. Output Directory: leave empty.
6. Click Deploy.
